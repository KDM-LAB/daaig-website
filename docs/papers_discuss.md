| 🎤 **Speaker** | Dhiraj Golhar (Research scholar)|
| 📅 **Date** | |
| 📄 **Paper Title** | *Generative Adversarial Network: Use of Non-IID Samples* |
| 🧠 **Abstract** | <details><summary>View Abstract</summary> The generative adversarial network (GAN) represents a useful generative model inspired by the theory of two-person zero-sum games. One may use such models in image generation, text generation, image super-resolution, adversarial attacks, defense, etc. In its naive form, the generator aims to synthesize the real data that fools the discriminator by accepting independent and identically distributed (IID) noise as input, while the discriminator improves itself to distinguish between the real training data and the fake data generated by the generator. In this paper, we proposed an approach in which the generator uses the statistical characteristics of the training data through the input noise by using non-iid samples obtained using the training data. The training data is modeled as a multivariate Gaussian distribution, and the mean vector and covariance matrix are extracted from the data, which are used to draw the non-IID samples from this distribution. After training, using the features from training data in the form of non-IID samples, the generator learns the distribution of original real data faster than the IID case and also enhances the accuracy and
diversity of the GAN model. </details> |

| 📄 **Paper Title** | *Introduction to Graph Signal Processing and Application* |
| 🧠 **Abstract** | <details><summary>View Abstract</summary> Graph Signal Processing (GSP) is an emerging field that extends classical signal processing techniques to data defined on irregular, non-Euclidean structures represented by graphs. By modeling complex relationships as graphs, where nodes represent data points and edges capture dependencies, GSP provides a powerful framework for analyzing and processing high-dimensional, interconnected data. This abstract overviews the core principles of GSP, including graph Fourier transforms, spectral graph theory, and graph filters, which enable the analysis of signals in the graph frequency domain. Key applications span diverse domains, such as social network analysis, sensor networks, image processing, and machine learning, where GSP facilitates tasks like denoising, sampling, clustering, and anomaly detection. Recent advances in GSP incorporate time-varying graphs and deep learning, addressing challenges in scalability and dynamic data. This field continues to evolve, offering robust tools for understanding and leveraging the intricate structures of modern data systems. </details> |

| 🎤 **Speaker** | Bhargav Dave (Research scholar)|
| 📅 **Date** | |
| 📄 **Paper Title** | *SqCLIRIL: Spoken query cross-lingual information retrieval in Indian languages* |
| 🧠 **Abstract** | <details><summary>View Abstract</summary> This paper presents SqCLIRIL (Spoken Query Cross-lingual Information Retrieval in Indian Languages), a comprehensive benchmark designed to evaluate spoken query-based cross-lingual retrieval across five Indian languages: Hindi, Gujarati Bengali, Kannada, and English. The task encompasses monolingual and cross-lingual retrieval settings across five language pairs, incorporating spoken queries (male and female voices) and document collections in text. The primary objective is to assess retrieval effectiveness in a low-resource multi lingual setting that reflects real-world language diversity and access constraints. We investigate four retrieval architectures: (i) sparse lexicalmatching using BM25, (ii) dense semantic retrieval via bi-encoder models, (iii) hybrid ranking through Reciprocal Rank Fusion (RRF) of sparse and dense scores, and (iv) a Large Language Model (LLM)-based pointwise fusion strategy (LPF) that integrates generative semantic alignment. Experimental evaluations on the human-translated TREC DL’19 and DL’20 query sets in the above five languages show that while dense retrieval improves substantially over traditional sparse models, fusion-based approaches—particularly LPF—consistently yield superior nDCG scores across most query- document language pairs. The results underscore the utility of generative AI in enhancing retrieval performance in multilingual, low-resource, speech-centric IR scenarios. This benchmark contributes to developing scalable, speech-first, and language-agnostic retrieval systems, with implications for inclusive information access in linguistically fragmented regions. </details> |
